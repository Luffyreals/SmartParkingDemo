6 màn hình quản lý toàn diện

Thiết kế tối ưu tốc độ phản hồi với bộ nhớ đệm TTL, hiệu ứng skeleton loading và bảng dữ liệu hiện đại.

01

Tổng quan & Sơ đồ bãi

5 KPI thời gian thực, thẻ công suất 3 bãi đỗ kèm địa điểm, tỷ lệ lấp đầy từng khu vực, lưới ô đỗ trực quan và thêm nhanh ô đỗ mới.

02

Vào / Ra bãi xe

Check-in cấp thẻ và khóa ô đỗ trong transaction; tự nhận diện vé tháng; tính phí dự kiến và thanh toán check-out an toàn.

03

Lịch sử giao dịch

Tra cứu biên lai thu phí theo khoảng thời gian, loại xe, biển số, mã thẻ hoặc nhân viên trực kèm nút xuất báo cáo CSV.

04

Vé tháng & Bảng giá

Quản lý thuê bao vé tháng, đăng ký mới kèm ước tính chi phí tự động và tra cứu bảng giá niêm yết theo đối tượng.

05

Thống kê doanh thu

Biểu đồ Altair trực quan hóa doanh thu theo ngày, lưu lượng lượt xe, cơ cấu loại phương tiện và so sánh theo từng bãi đỗ.

06

Nhân sự & Khách gửi xe

5 tab chuyên sâu: Nhân sự vận hành, Giảng viên & Sinh viên, Khách vãng lai, Kho thẻ xe RFID và Danh bạ phương tiện.

Cài đặt & Chạy thử trong 4 bước

Do ứng dụng sử dụng Streamlit và kết nối SSL trực tiếp tới TiDB Cloud, bạn chạy ứng dụng trên môi trường Python local (GitHub Pages chỉ phục vụ trang giới thiệu này).

# 1. Clone repository & tạo môi trường ảo git clone https://github.com/Luffyreals/SmartParkingDemo.git cd SmartParkingDemo python -m venv .venv .\.venv\Scripts\Activate.ps1 # 2. Cài đặt thư viện & nạp schema Dump20261118.sql vào TiDB / MySQL pip install -r requirements.txt # 3. Cấu hình .streamlit/secrets.toml (hoặc biến môi trường TIDB_*) # [tidb] host, port = 4000, database = "dbptit", user, password # 4. Chạy ứng dụng & kiểm thử streamlit run src/app.py python -m unittest discover -s tests -v
